# Welcome to EMQ on GitHub

EMQ builds the **world's most scalable MQTT platform**, powering real-time data movement for AI, IoT, IIoT, and connected vehicles. Trusted by thousands of enterprises, our projects connect and move data reliably across **billions of devices** worldwide.

Explore our unified platform at [www.emqx.com](https://www.emqx.com/en).

## Core Projects

- **[EMQX](https://github.com/emqx/emqx)**  
  The most scalable and reliable MQTT broker — supports **10M+ concurrent connections** with ultra-low latency for mission-critical IoT and AI applications.
- **[MQTTX](https://github.com/emqx/MQTTX)**  
  All-in-one MQTT 5.0 client toolbox: intuitive Desktop app, powerful CLI, and Web-based client for testing and debugging.
- **[Neuron](https://github.com/emqx/neuron)**  
  Industrial IoT connectivity server supporting **100+ protocols**. Open-source core with full-featured enterprise edition ([EMQX Neuron](https://www.emqx.com/en/products/emqx-neuron)).

## MQTT SDKs & Client Resources

- **[FlowSDK](https://github.com/emqx/flowsdk)**  
  A safety-first, behavior-predictable MQTT 5.0 SDK written in Rust.
- **[NanoSDK](https://github.com/emqx/NanoSDK)**  
  High-performance, MQTT 5.0-compliant C SDK with QUIC support.
- **[MQTT Client Examples](https://github.com/emqx/MQTT-Client-Examples)**  
  Ready-to-use MQTT client examples and SDK wrappers in **20+ languages**.
